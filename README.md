# ☕ Coffee Love  

A beautifully designed coffee-themed website built with **HTML, CSS, JavaScript, and Bootstrap**. It showcases the love for coffee with an elegant UI, smooth animations, and engaging content.  

## 🌟 Features  
- **Responsive Design** – Works seamlessly across all devices.  
- **Bootstrap-Powered UI** – Ensures a modern and sleek look.  
- **Interactive Elements** – Smooth animations and effects.  
- **Coffee Insights** – Learn about different types of coffee and brewing methods.  
- **User-Friendly Navigation** – Simple and intuitive design.  

## 🛠️ Technologies Used  
- **HTML** – Structure of the website  
- **CSS** – Styling and layout  
- **JavaScript** – Interactivity and animations  
- **Bootstrap** – Responsive framework
